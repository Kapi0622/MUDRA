# MUDRA 必要サウンド素材リスト（B7）

素材探し用のリスト。どこで鳴るか（配線元のコード）・素材の差し替え方・ARC の作り方は [architecture/03_sound.md](architecture/03_sound.md) にまとめた（B7）。
欄の中身（どの素材が入っているか）は `SND_Sound` と各アセットが正。このリストは素材の目安と入手記録の置き場所。

- 優先度: **A** = 遊びに直結（最低限これだけは揃える） / **B** = 演出の格 / **C** = あれば良い
- 長さはあくまで目安。演出の尺（`PresentationTimingData`）に合わせて後で切り詰めてよい
- 「探す語」は素材サイトで検索するときのキーワード

## 命名規則

**ファイル名は英語（ASCII）の `プレフィックス_PascalCase` にする。** 仕様書 §3-2「アセット命名規則（B3で制定）」に揃えるため。
日本語ファイル名は git や Windows の文字コードで事故が起きやすく、Unity のアセット検索もしにくい。日本語名はこの表の中でだけ使う。

| 種別 | プレフィックス | 例 |
|---|---|---|
| 効果音 | `SE_` | `SE_SignConfirm` |
| 術の発動音（`SpellData.castSE`） | `SE_Cast_` + 術アセット名 | `SE_Cast_WindBlade` |
| 敵の攻撃音（`EnemyAttackData.attackSE`） | `SE_EnemyAtk_` + 系統 | `SE_EnemyAtk_Fire` |
| BGM | `BGM_` | `BGM_Stage01_SealedVillage` |
| ジングル（数秒で終わる曲） | `JGL_` | `JGL_Victory` |
| Audio Random Container | `ARC_` + 元の素材名から `SE_` を除いたもの | `ARC_EnemyAtk_Fire`（中身は `SE_EnemyAtk_Fire`） |

同じ用途で複数のバリエーションを用意するときは末尾に `_01`, `_02` を付ける（例: `SE_Hit_01`）。

## 音の方向性

**和楽器 ＋ 現代的な低音・打撃のハイブリッド。**

| 役割 | 楽器・音色 |
|---|---|
| 打撃・決め | 和太鼓、締太鼓、拍子木 |
| 術・印 | 鈴、錫杖、りん（仏具）、金属の響き |
| 不穏・予告 | 能管・篠笛の高い音、法螺貝、銅鑼、低いドローン |
| 柔らかい情緒 | 琴、尺八、三味線、風鈴 |

### 術ごとの発動音（`SpellData.castSE`、8種）
