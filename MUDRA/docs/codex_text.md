# 図鑑の説明文（下書き）

図鑑（ステージ選択から開く「術／妖」）の詳細パネルに出す説明文。**ここで文章を直してから、SO の `description` に流し込む**（流し込みは Claude が MCP で行う）。

## 書き方の決まり

- 1本 **2〜3文・60〜90字**。詳細パネルと `TextArea(2,4)` に収まる長さ
- 調子は伝承・巻物の一節。ただし**最後の一文は遊び方のヒント**にする（ゲームを覚える手間を減らすため）
- **数値は書かない**（威力・体力は図鑑側で★にして出す。弱点属性・印の並び・攻撃名も図鑑側で別に出るので、本文で繰り返さなくてよい）
- 世界観: 古代から伝わる秘術「印術」で、封じられていた妖と戦う和風ファンタジー（企画書 §7-1）
- 木人（`ED_TrainingDummy`）は図鑑に載せない
