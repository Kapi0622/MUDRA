## 2. 決めた方針（論点と結論）

| # | 論点 | 結論 | 補足 |
|---|---|---|---|
| 1 | Stun 完封対策 | **確率化（逓減つき）** | 確率 = 基本 60% × 敵ごとの倍率 × 0.5^(同じ敵に続けて入った回数)。外れる・敵が替わると基本に戻る |
| 2 | 純粋な確率にしなかった理由 | 確率だけだと運次第で止め続けられる（50%でも3連続 12.5%） | 逓減で長い連鎖をほぼ起きなくし、運の要素（ユーザー希望）は残す |
| 3 | 免疫期間を見送った理由 | 「今は効かない」を出し続ける表示が要り、伝え方が難しい | 確率なら外れを「抵抗」の一言で伝えられる |
| 4 | 判定しない場面 | 倒した一撃・既に Stun 中の敵への一撃 | どちらも Stun は掛からないので、判定すると回数だけ進む・「抵抗」が出る |
| 5 | SO 化の範囲 | 仕様書の2つ（ガード受付時間・速度ボーナス）に加え、**全体の調整値を1つに** | PlayerMaxHp・暴発・ガード軽減・コンボ・連続減衰・Stun。DoT の比率・HoT の間隔・ランクは対象外 |
| 6 | PlayerMaxHp・コンボ上限 | B7.5 の値（100・×1.3）で確定 | |
| 7 | 業火（4印・威力175）への偏り | **修正しない** | 連続減衰で威力が下がり数字も灰色になるので、続けて撃ちたくならない（ユーザーの体感） |
| 8 | 敵の攻撃力 | 通常 ×1.5・大技 ×1.75 | 慣れた人なら S1〜2 は余裕、他も負けない程度に弱かった。大技を多めに上げ、ガードした／しないの差を広げる |
| 9 | 回復術 | 35 → 50（約 ×1.4） | 被ダメージの伸び（約 ×1.7）より小さくし、回復で押し切れないようにする |
| 10 | ボスの行動パターン | 影縫いの溜め 1.0 → 1.3 秒のみ | 予告を見てからガードが間に合わないギリギリだった。影法師にも効く |
| 11 | 値を変える場所 | 攻撃・敵は `B3ContentGenerator` の表、術はアセット直、全体は `BD_Balance` | 攻撃は複数ステージで使い回しているので、ステージ別でなく攻撃ごとに一律で上げた |

## 5. 技術的負債・保留事項

| 項目 | 内容 |
|---|---|
| 業火の偏り | 早見表では、弱点でない術の中でほぼ全敵の最速。連続減衰で体感上は問題なしと判断。初見プレイヤーで偏るようなら再検討 |
| 雷の弱点 | 雷の術は雷連撃（威力 85）だけで、河童・水蛇では業火のほうが早く倒せる。弱点を突くうまみが小さい |
| 攻撃の使い回し | 1つの攻撃を複数ステージの敵が使うので、ステージ別に強さを変えられない。必要なら攻撃を分ける |
| `UnityEngine.Random.value` | 1.0 ちょうどを返すことがある。確率 1 以上は乱数を見ずに入れることで回避 |
| `TempHandTrackingRunner` の NRE | B6.5 から持ち越し |
